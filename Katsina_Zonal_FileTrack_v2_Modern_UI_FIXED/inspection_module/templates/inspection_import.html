Import Corps Members

Upload Excel (.xlsx) or CSV. Existing State Codes are updated; new State Codes are inserted.

Required columns

State Code, Corps Member Name, PPA / Establishment, LGA

Optional: Gender, Discipline, Batch, Stream, Phone, Status.

The system treats PPA/Establishment as the single field. place_of_posting and ppa_employer are not separate fields.
