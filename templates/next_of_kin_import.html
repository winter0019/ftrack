Import Next of Kin, ICE & ICD

Import or update the three official contact categories for Corps Members in a selected LGA. Each record is matched using the Corps Member's State Code.

Next of KinPrimary next-of-kin contact
ICEIn Case of Emergency
ICDIn Case of Death

You may select multiple files generated by the Katsina Auto Agent or exported from the original NYSC portal.

Supported contact columns
Next of Kin: Next of Kin, Next of Kin Name, Relationship, GSM No., Phone, Address
ICE: In Case of Emergency, Emergency Contact, Emergency Relationship, Emergency Phone, Emergency Address
ICD: In Case of Death, Death Contact Relationship, Death Contact Phone, Death Contact Address
Matching: State Code is required. LGA must match the selected LGA and the Corps Member's directory assignment.

Import safeguards
  • Next of Kin, ICE and ICD are stored independently.
  • Blank incoming fields do not erase existing contact information.
  • Multiple files for the same State Code are merged; later nonblank values take precedence.
  • Rows with no contact data are counted as skipped, not treated as contact-data errors.
  • Legacy NOK 1/2/3 exports use NOK 1 as the primary Next of Kin. NOK 2 and NOK 3 are not silently mapped to ICE or ICD.
