Import Next of Kin & Emergency Contacts

Import or update Next of Kin 1, 2 and 3, Emergency (ICE), and In Case of Death (ICD) records for a selected LGA. Each record is matched using the State Code.

Select one or multiple files generated by the Katsina Auto Agent.
Supported File Header Columns:
  • State Code — required for record matching
  • Next of Kin 1: Next of Kin 1, Relationship 1, Phone 1, Address 1
  • Next of Kin 2: Next of Kin 2, Relationship 2, Phone 2, Address 2
  • Next of Kin 3: Next of Kin 3, Relationship 3, Phone 3, Address 3
  • ICE: Emergency Contact (ICE), Emergency Relationship, Emergency Phone, Emergency Address
  • ICD: In Case of Death (ICD), Death Contact Relationship, Death Contact Phone, Death Contact Address
Important:
• The State Code must already exist in the KATZIMS Directory and belong to the selected LGA.
• Mismatched LGA or unrecognised State Codes are flagged and skipped.
• For a new record, NOK 1 Name is required because it is the primary contact.
• For an existing record, blank incoming fields do not erase existing contact data.
• Multiple uploaded files containing the same State Code are merged rather than allowing one file to erase another file's contacts.
