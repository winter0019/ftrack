Corps Members Directory

Upload the zonal corps members master list for general LGI directory searches. This import is separate from inspection assignments. Existing State Codes are updated and new State Codes are added without deleting existing records.

Accepted NYSC workbook format

The system reads the Expected sheet when it exists. It also accepts the consolidated All Corps Members sheet in Katsina_Zonal_Corps_Members_By_LGA.xlsx.

For the consolidated master, it maps State Code → State Code, Name → Name, Establishment → PPA/Establishment, and LGA + Component → the seven zonal LGAs.

For raw NYSC downloads, it maps Statecode → State Code, Surname + Othernames → Name, and Company → PPA/Establishment.

Course, Gender, GSMNO, Stream and the batch in the State Code are also imported.

Example: rimiC.xlsx, rimiA.xlsx and rimi.xlsx are automatically treated as Rimi. The A/C/unsuffixed suffix is treated as the NYSC batch, not as the LGA.

For katsinaC.xlsx, katsinaA.xlsx and katsina.xlsx, select Katsina A or Katsina B because the filename alone does not identify the component. The consolidated zonal master already contains the Component column, so no manual selection is needed.

Existing State Codes are updated; new State Codes are inserted. Existing PostgreSQL data is not deleted or reset.
